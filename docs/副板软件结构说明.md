# 副板软件结构说明

## 职责划分

`main.c` 仅负责调用 `System_Init()`、`AppTasks_Create()` 并启动 FreeRTOS。

`system_init.c` 负责时钟、日志、全局互斥锁与 GPIO/DMA 基础时钟；不包含电机、CAN 或 UART 业务初始化。

`app_tasks.c` 负责创建任务和保存任务句柄。电机任务收到 ADC 中断通知后调用 `MotorService`；CAN、UART 和状态任务只调用各自业务接口。

`task_config.h` 集中保存应用任务的开关、优先级和栈大小。中断优先级仍保留在 `sys_cfg.h`。

`motor_service.c` 负责电机初始化及每次控制调用，保持原 FOC、速度/电流模式选择不变。历史变量 `g_motor1` 是物理 Motor0（左轮、TMR1），`g_motor2` 是物理 Motor1（右轮、TMR8）。

`can_business.c` 负责 CAN ID、帧解析、超时和遥测；`my_can.c` 只负责 CAN 硬件收发。

`uart_business.c` 负责当前 UART 文本遥测和接收回调；`my_usart.c` 只负责 UART BSP。

## 结构图

```text
main
 ├── System_Init
 ├── AppTasks_Create
 └── FreeRTOS
     ├── Motor0Task → MotorService → FOC
     ├── Motor1Task → MotorService → FOC
     ├── CanTask    → can_business → my_can
     ├── UartTask   → uart_business → my_usart
     └── StatusTask → system_monitor
```

## 扩展方式

新增 FreeRTOS 任务时：在 `task_config.h` 增加开关、优先级和栈大小；在对应业务模块提供初始化/周期处理接口；最后在 `app_tasks.c` 创建轻量任务入口。临时关闭任务只需将对应 `APP_TASK_*_ENABLE` 设为 `0`。

CAN 协议、CAN ID、解析和遥测应添加到 `Communication/can_business.c`；CAN 外设初始化、过滤和收发驱动应添加到 `HardwareLayer/my_can.c`。
